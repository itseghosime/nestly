## 7. Phase 2: Complete Motion & Interaction Pass

### Motion Architecture & System Principles
- **Single Coordinated Animation System**: Uses `gsap` + `@gsap/react` (`useGSAP`, `ScrollTrigger`) for coordinated entrances, shared-element transitions, drawers, and sequenced feedback, paired with CSS transitions (`cubic-bezier(0.22, 1, 0.36, 1)`) for lightweight hover, focus, and active press micro-interactions (`120ms–220ms`). No competing animation libraries (e.g., Framer Motion) were added.
- **Shared Motion Foundations (`lib/motion.ts` & `app/globals.css`)**:
  - Defined duration, easing, and distance tokens (`MOTION`).
  - Added `@property --animation-reduced` CSS custom property scaling and `prefers-reduced-motion: reduce` support across both CSS and GSAP (`useReducedMotion()` / `prefersReducedMotion()`).
  - Gated card hover lift and image zoom behind `@media (hover: hover) and (pointer: fine)` so touch devices never experience sticky hover states.

### Key Experiences Delivered
1. **Signature Experience: Property Card → Detail Hero Transition (`lib/property-transition-context.tsx`)**:
   - Clicking a `PropertyCard` image or title link on `/`, `/browse`, `/saved`, `/neighborhoods/[slug]`, or related listings on `/property/[id]` captures the card image's exact bounding rect (`getBoundingClientRect`), image source, and border radius.
   - Renders a fixed high-z-index portal overlay that morphs smoothly into the destination `[data-property-hero]` container (`520ms` `power3.inOut`) while destination header, badges, and booking card stagger in around it.
   - Preserves standard `<Link>` semantics: modified clicks (`Cmd/Ctrl/Shift/Alt` + click, middle click), right-click context menus, keyboard activation, and direct URL loads work naturally.
   - Automatically saves and restores listing scroll position (`sessionStorage`) when navigating Back to `/browse`, `/`, `/saved`, or `/neighborhoods/[slug]`.
   - Bypasses spatial morphing cleanly when `prefers-reduced-motion: reduce` is active.
2. **Public Website Composed Motion**:
   - **Home (`/`)**: Composed hero text stagger, architectural hero frame reveal, sunlit cutout badge entrance, ScrollTrigger reveals (`once: true`) for editorial sections, GSAP crossfade/reflow when switching Featured Homes categories, sequential WhatsApp mockup bubble reveal, and controlled FAQ accordion transitions.
   - **Browse (`/browse`) & Saved (`/saved`)**: Animated filter drawer, tactile filter chips, smooth card grid stagger on filter/sort updates, animated card exit collapse on removal from Saved Homes, and animated Shortlist Preview modal.
   - **Property Details (`/property/[id]`)**: Crossfade gallery switcher, accessible full-screen Lightbox modal with keyboard arrow navigation (`ArrowLeft`, `ArrowRight`, `Escape`), and animated cost breakdown bars.
   - **Inspection Booking (`/inspection-request` & `/inspection-request/received`)**: Validation shake on incomplete fields, smooth step transitions, and a composed checkmark + gate-pass flourish on confirmation.
3. **Nia Assistant Presence (`components/public/NiaWidget.tsx`)**:
   - Subtle, calm floating launcher (`Ask Nia · Demo`) with zero distracting infinite pulse/bounce loops or unsolicited auto-openings.
   - Smooth GSAP open, minimize-to-pill bar, and close animations (`Escape` key supported).
   - Explicit conversation states (`data-nia-state`): `idle`, `composing`, `waiting`, `replying`, `error` (with simulated retry), and `human-handoff` (local demonstration summary card).
   - Renders the typing/pending indicator (`data-testid="nia-typing-indicator"`) **strictly** while a reply is pending (`waiting`/`replying`), with an immediate `Cancel` control.
   - Smart auto-scroll that only scrolls automatically when the user is near the bottom, revealing a floating `"New message ↓"` pill when scrolled up.
4. **Staff Auth & Operations Dashboard Motion**:
   - Crisp operational timing (`140ms–240ms`) across all 5 staff auth routes and 19 staff dashboard routes, including animated `StaffSidebar` mobile drawer (`Escape` + backdrop close), interactive pipeline tabs, message bubble insertion in `/staff/inbox/[id]`, EDOGIS cadastre simulation progress, and audit-log slide-over drawer.
